# Guide d'utilisation : Déroulé de l'élection en classe

Ce guide accompagne l'enseignant de CM1 ou CM2 pour organiser une élection démocratique et sereine en classe.

## Phase 1 : Préparation civique (J-15 à J-1)

1. **Découverte des modalités** : Consultez les fiches des 4 modes de scrutin avec vos élèves (interrupteur en mode `Élèves`).
2. **Choix de la modalité** : Choisissez le mode correspondant à vos objectifs pédagogiques (parité stricte via binôme, vote préférentiel Borda ou vote corrigé).
3. **Campagne électorale** : Déclaration des candidatures et rédaction des professions de foi.
4. **Matériel** : Imprimez les bulletins officiels, prévoyez une urne transparente, des enveloppes opaques et un isoloir garantissant le secret.

## Phase 2 : Configuration de l'application (Matin du vote)

1. Ouvrez l'application sur l'ordinateur de la classe ou le Tableau Numérique Interactif (TNI).
2. Rendez-vous dans l'onglet **Résultats / Dépouillement**.
3. Renseignez l'école, la classe, le nombre d'inscrits réels et la liste nominative des candidats avec leur sexe.
4. Si le mode binôme est choisi, associez les paires mixtes.
5. Cliquez sur **« Commencer le dépouillement »** pour figer les paramètres officiels.

## Phase 3 : Le vote des élèves (Jour J)

- Les assesseurs élèves contrôlent l'identité et font émarger chaque électeur.
- Chaque élève passe dans l'isoloir secret avant de déposer son bulletin dans l'urne.
- Le président annonce la formule rituelle : *« A voté ! »*.

## Phase 4 : Le dépouillement sur grand écran

1. Activez le **Mode Projection** (plein écran) pour faire participer toute la classe.
2. Deux élèves assesseurs dépouillent l'urne : l'un déplie le bulletin, l'autre annonce le choix.
3. Un élève ou l'enseignant clique sur le grand bouton correspondant sur le TNI (ou utilise les raccourcis clavier 1, 2, 3, B pour blanc, N pour nul).
4. La barre de progression et le tableau en direct se mettent à jour automatiquement.
5. Une fois tous les bulletins saisis, cliquez sur **« Clore le dépouillement »**.
